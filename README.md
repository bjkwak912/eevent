# 옮김 웹

- 서비스: https://eevent-eevent.mycafe24.ai/
- GitHub: https://github.com/bjkwak912/eevent
- Cafe24 프로젝트: `eevent-eevent` / 기존 무료 체험 공간

ISA·연금저축·IRP 이전 혜택을 비교하는 반응형 웹 데모. Android 앱과 같은 공식 자료를 사용한다. 금액 쉼표 표시, 10개사 목록, 상품 탭, 관심 저장, 상세 조건·공식 출처, 최대 3개 비교를 제공한다.

## 실행

Node.js 20 이상. 외부 패키지 설치가 필요 없다.

```sh
npm start
npm test
```

`http://localhost:3000`에서 확인한다. 서버는 Cafe24 AI SPACE 규칙에 맞게 `0.0.0.0:3000`에서 실행된다. 비밀 키와 데이터베이스를 사용하지 않는다. 브라우저 저장소에는 관심 항목과 입력 금액만 저장한다.

## 카페24와 GitHub

이 `web` 폴더가 독립 GitHub 저장소의 루트다. AI SPACE에서 `bjkwak912/eevent` 저장소의 `main`을 연동해 배포했다. 시작 명령은 `npm start`다. Dockerfile·별도 웹 서버 설정이 필요 없다. 2026-10-17 카페24 대시보드의 정상 운영 상태와 실제 HTTPS 접속, 금액 입력·상품 전환을 확인했다. 로컬 저장소의 `origin`도 연결했다. 최초 로컬 커밋은 `local-snapshot` 브랜치에 보존했다.

`public/catalog.json`이 사이트에서 읽는 검토 발행 자료다. 상위 Android 작업 폴더의 publisher가 공식 조건 변경 시 이 파일도 갱신한다. 정오 점검은 변경된 자료를 GitHub에 올린 뒤 Cafe24 배포 상태와 실제 반영을 확인한다. 웹은 APK 설치 없이 페이지를 새로고침하여 배포된 자료를 확인할 수 있다. 자동 재배포 실패 시 관리 화면에서 배포를 확인하며, 성공을 확인하기 전 갱신됐다고 안내하지 않는다.

2026-10-19 자료(revision 3): 기본 계산 가능 21개, 참여 대상 제한 1개, 현행 행사 확인 필요 8개. 대신증권 ISA·연금저축·IRP를 공식 포스터와 브라우저에서 렌더링된 상세 각주로 추가 검증했다. 금액은 조건부 액면 기준이며, 포인트는 현금과 구분한다. 대신증권의 5만원 초과 혜택은 고객 부담 제세공과금으로 실제 수령 가치가 줄어들 수 있음을 상세에 표시한다. 모든 조건 충족 여부와 최종 지급은 공식 안내를 따른다.
