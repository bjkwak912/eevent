# 옮김 웹

ISA·연금저축·IRP 이전 혜택을 비교하는 반응형 웹 데모. Android 앱과 같은 공식 자료를 사용한다. 금액 쉼표 표시, 10개사 목록, 상품 탭, 관심 저장, 상세 조건·공식 출처, 최대 3개 비교를 제공한다.

## 실행

Node.js 20 이상. 외부 패키지 설치가 필요 없다.

```sh
npm start
npm test
```

`http://localhost:3000`에서 확인한다. 서버는 Cafe24 AI SPACE 규칙에 맞게 `0.0.0.0:3000`에서 실행된다. 비밀 키와 데이터베이스를 사용하지 않는다. 브라우저 저장소에는 관심 항목과 입력 금액만 저장한다.

## 카페24와 GitHub

이 `web` 폴더가 독립 GitHub 저장소의 루트가 된다. AI SPACE에서 GitHub 저장소를 연동해 Node.js 20 런타임으로 배포한다. 시작 명령은 `npm start`다. Dockerfile·별도 웹 서버 설정이 필요 없다. 배포 도구 연결과 계정 OAuth 완료 후 프로젝트 생성·배포·실제 접속 검증을 수행한다.

`public/catalog.json`이 사이트에서 읽는 검토 발행 자료다. 상위 Android 작업 폴더의 publisher가 공식 조건 변경 시 이 파일도 갱신한다. 웹은 APK 설치 없이 페이지를 새로고침하여 배포된 자료를 확인할 수 있다. 정오 점검의 웹 Git 커밋·push·재배포 단계는 GitHub·AI SPACE 최초 연결 후 추가한다. 현재 자동 재배포가 연결된 것으로 안내하지 않는다.

2026-10-17 자료: 기본 계산 가능 15개, 참여 대상 제한 1개, 세부 검증 중 5개, 현행 행사 확인 필요 9개. 금액은 조건부이며, 포인트는 현금과 구분한다. 모든 조건 충족 여부와 최종 지급은 공식 안내를 따른다.
